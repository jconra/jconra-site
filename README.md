# jconra-site
Jacob Conrads' portfolio, served at jconra.com and jacobconrads.com. Static: no build step.

- `index.html` + `src/quarters.js` — the landing film. `/?edit` opens its editing panel (the Quarters Lab).
- `projects/` — finished ideas, one folder each, including the 2019 site (`projects/old-site/`) and the
  DuckCon game tutorial.
- `labs/` — small experiments that help a bigger project without belonging to one.
- `src/` — shared modules the film and labs import.
- `models/`, `textures/`, `fonts/` — shared assets.
- `unused_code/` — kept for reference, not served from anywhere.
