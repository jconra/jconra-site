Shipwrecked

This is a survival game that starts you on a shipwrecked island. It generates the terrain based off of a seed which allows lots of possibilities.

This game lets you build walls and choose gem towers. Then enemies come out and use the A-Star path-finding algorithm to work their way through your maze (unfinished).

A great demonstration of the A-Star path-finding algorithm. Generates random maps and Gives controls to see detailed information.

Color Fun

This little app was made for my kids and lets you mix colors to see the result. You can stir around in a color to get more of it. Works on mobile.

Space Game

A game that is actually complete. You try to save the pods in the asteroid field.

Simple Maze

This page generates a maze and shows you the path from one corner to the opposite corner. It uses a custom A* that detects if there are multiple routes and seals them so there is only one solution and every part of the maze is accessible.

3D Maze

The second part of the maze project, this uses a home-built 3D engine to spin it around and move it.

Inside the 3D Maze

This maze is like the old screensaver that navigates through a large maze. It could be used as a slideshow. It also allows you to manually navigate with WASD. Uses Three.js Library and A* pathfinding.

Missile Defense
