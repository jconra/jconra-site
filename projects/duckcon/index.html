HTML Games.. Learn Programming the fun way!



If you have an interest in programming and are not sure where to start, this could be the tutorial you are looking for. This is by no means the best place to learn all about HTML or JavaScript, but hopefully these pages can show you how easy it is to get started and provide you the modivation to write your first program!

There are many reasons to take up programming, you can write scripts to make work easier. It can help you get a better job. Also, you might find it to be an enjoyable experience. Programming can provide a similar challenge to a puzzle, and have a satisfying feeling when it works.

Why Use JavaScript and Canvas?

According to Stack Overflow Surveys, JavaScript is the most popular programing language. You can easily start programing on any computer since all you need is a text editor and a browser. If you only have notepad then it will benefit you to get Notepad++. Any browser such as Chrome, Firefox or Edge will run your code. It is easy to troubleshoot problems using the browser's developer tools (Press F12). Developer Tools give you access to the Console, Debugger, and other tools that make it easy to figure out problems.

The HTML5 canvas is a good way to make something visual. You might be a visual learner and it can be fun to manipulate the canvas. It doesn't take very much code to get things working and there is great help online.

If you want to learn the basics of HTML, CSS or Javascript, check out: w3schools.com

Aren't games in the browser really limited?

Javascript can access WebGL and take full control of your video card. This can give you pretty impressive 3D graphics. If you are interested in 3D graphics, using a Javascript library like Three.js can make development pretty easy. Check out this WebGL Quake 3 Demo or the Three.js Homepage to see what JavaScript games in the browser are capable of.
