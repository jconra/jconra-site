You can enter an IP Address using shorthand notation:
Or using a subnet mask:


If you are practicing then you can fill out the boxes on your own. When you press the Show Answers button any boxes that you have attempted will either turn green or red depending on if you answered correctly or not. If the box is empty then the correct answer will be shown in the box. Therefore, if you are having trouble solving for a box you can clear it and click the Show Answers button to see what answer the calculator was looking for.

The drop down menu will fill in the binary representation of whatever you select from the drop-down. The Show Colors button is able to help you solve without giving away all the answers.
