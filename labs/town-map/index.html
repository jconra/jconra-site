Town Map

Draw the town as seen from above: 1 pixel is 1 metre, 600 m across, north up. The fighter arrives from the bottom (south). Paint roads and grass, drag out buildings (each one is a project, in the order you draw them), click out the fence in runs with gaps for gates. What you don't paint is forest floor.

Tool

14 m

Lines snap to the grid when they are within 3 m of it, so streets meet cleanly.

The fence is drawn in runs: click post after post, then End run (or Esc) and start the next run elsewhere. The gap between two runs is a gate.

Buildings

In the order drawn: each rectangle is the next project in the list below. Click one to delete it. Height is set from the footprint; the roof shows the project's picture.

Save

Download the map picture and copy the JSON; put the picture in the S3 bucket (or textures/town/) and paste the JSON in chat, and I bake both into the town.
